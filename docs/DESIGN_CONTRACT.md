# Desktop design contract

The supplied five-workspace reference is authoritative. No new design concept.

- Near-black canvas #101213; rail #191c1e; paper/panels #1a1e20; thin #303638 borders; signal #c8f135. Native Kinetic Paper tokens were inspected; their purple/paper treatment conflicts with the approved desktop reference and is not carried over.
- Full-height left rail, approximately 15% of desktop width (216px at 1440); restrained outline icons; active navigation is lime text with a subtle filled row and a left signal.
- UI: system sans, 14px body, 12px metadata, 28px page heading. Reading: Georgia, 20px, generous leading. Controls at least 44px. Small 6–9px radii. No blur, decorative gradients or large shadows.
- Home: title, four metrics, then two parallel lists for continue reading and insights. Library: title/import, full-width search, chips/sort, four-column book grid, recently opened rows. Reader: narrow contents, large dark document sheet, contextual inspector. Study: six compact actions in a 3×2 grid followed by a progress strip. Trails: spatial network and related-content inspector.
- Reuse shell, book covers, progress lines, source links, list rows, tabs and section headers. Motion is 180–220ms and disabled for reduced motion.
- Reference commercial titles become the six original bundled sample titles. Counts reflect actual local state. No fake macOS window controls. Home uses a neutral greeting because a recruiter's name is unknown.
- Reference/handoff labels: Library, Study, Trails, Explore, Notes, Home, Settings; Import PDFs; Learning Lab; Connections; Explain, Quiz, Teach, Discuss, Summarise, Apply; Continue learning; Recently opened; Recent insights. Additional labels serve required forms, provenance, reset, privacy and accessibility.
